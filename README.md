# Arc Onchain Guestbook

An onchain guestbook built on Arc Testnet using Arc Studio.

Users can connect their wallet and leave messages that are recorded through a smart contract, demonstrating a simple onchain user interaction.

## Live Demo

https://cheery-maamoul-b6d3a1.netlify.app/

## Smart Contract

**Network:** Arc Testnet

**Contract Address:**

`0x68f59fddff891f764d46098dfe3843ce4ce69814`

## Features

- Wallet connection
- Onchain guestbook messages
- Smart contract interaction
- Wallet-based user identity
- Built on Arc Testnet
- Non-custodial
- Built and tested with Arc Studio

## Tech Stack

- Arc Testnet
- Solidity
- TypeScript
- React
- Tailwind CSS
- Vite
- Bun
- Foundry
